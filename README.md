# 리스크관리 포털 사용법

부서 리스크관리 정보를 한 페이지에 모은 포털입니다. `index.html`을 더블클릭해 웹 브라우저로 열면 바로 사용할 수 있습니다. 설치나 인터넷 연결은 필요 없습니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 포털 본체(한 파일로 완결) |
| `README.md` | 이 사용법 |
| `files/risk-management-guide.pdf` | 리스크관리 추진 가이드 |
| `files/risk-response-reporting-rules.pdf` | 리스크 대응·보고 규범 |
| `이전버전/portal-v2.html` | 이름을 바꾸기 전의 원본 사본 |

## 메뉴 안내

화면 위쪽 메뉴를 누르면 해당 위치로 이동하고, 스크롤하면 현재 위치가 메뉴에 표시됩니다. 화면이 좁으면(너비 900px 이하) 메뉴가 오른쪽 위 햄버거 버튼(☰)으로 접힙니다. 버튼을 누르면 메뉴가 펼쳐지고 버튼이 닫기(✕)로 바뀌며, 메뉴 항목을 누르면 해당 영역으로 이동하면서 메뉴가 자동으로 닫힙니다. 메뉴 바깥을 누르거나 Esc 키를 눌러도 닫힙니다. 지금 보고 있는 영역의 메뉴 항목은 색을 채우고 굵게 표시되며, 메뉴를 열면 어느 영역을 보고 있는지 바로 알 수 있습니다.

| 메뉴 | 볼 수 있는 내용 |
| --- | --- |
| 홈 | 포털 소개, 역할 알아보기·자가점검 바로가기 |
| 역할 | 스트레스테스트, 리스크 규제, 리스크관리 개선, 한도 관리·모니터링 역할과 개선 추진 4단계 |
| 리스크 관리 현황 | 개선 전/후 비교, 개선 우선순위 자가점검, 리스크관리 통제 안내와 공식 제보 채널 |
| 리스크 규제 뉴스 | 규제 동향과 공지 목록 |
| FAQ | 자주 묻는 질문과 검색 |
| 자료실 | 업무 양식 내려받기 |

## 기능별 사용법

### 개선 우선순위 자가점검
1. 「리스크 관리 현황」에서 보유·운용 자산(주식, 채권, 파생상품)을 체크합니다.
2. 오른쪽에 개선 우선순위(낮음·보통·높음)와 권장 조치가 바로 표시됩니다.
3. 점수는 주식 1점, 채권 1점, 파생상품 2점을 합산합니다. 1점은 낮음, 2점은 보통, 3점 이상은 높음입니다.
4. 「선택 초기화」를 누르면 처음 상태로 돌아갑니다. 참고용 간이 점검이며 공식 평가가 아닙니다.

### FAQ 검색
검색창에 키워드(예: 한도, 스트레스테스트, 제보)를 입력하면 일치하는 질문만 남고 답변이 펼쳐집니다. 검색창 아래 카테고리 버튼(전체·리스크 관리·규제 대응·한도 관리)을 누르면 해당 분류의 질문만 보이며, 버튼 옆 숫자는 그 분류의 질문 수입니다. 검색과 카테고리는 함께 적용됩니다(예: 「규제 대응」을 누르고 "보고"를 입력). 입력을 지우고 「전체」를 누르면 전체 목록으로 돌아옵니다. 각 답변 아래의 「근거」는 `files/` 안의 PDF 제목과 같습니다.

| 답변 아래 근거 표시 | 파일 |
| --- | --- |
| 리스크관리_추진_가이드 | `files/risk-management-guide.pdf` |
| 리스크대응_보고규범 | `files/risk-response-reporting-rules.pdf` |

### 공식 제보 채널 안내
「리스크관리 통제 안내」의 「공식 제보 채널 안내 보기」를 누르면 접수 채널·연락처·운영 시간 안내가 열립니다. 지금은 자리표시이므로 실제 사용 전에 기관 정보로 바꿔야 합니다(아래 「내용 수정하기」 참고).

### 자료실 양식 내려받기
「자료실」의 「다운로드 (CSV)」 버튼을 누르면 브라우저가 양식 파일을 저장합니다. 리스크 한도 내역과 규제 점검 양식 두 가지이며 엑셀에서 열 수 있습니다. 내용은 샘플 양식이므로 실제 수치와 기준에 맞게 고쳐 사용하세요.

### 참고 문서(PDF) 내려받기
「자료실」 아래 「참고 문서」 목록에 `files/` 폴더의 PDF가 파일명·설명·용량과 함께 표시됩니다. 「다운로드」 버튼을 누르면 PDF가 새 창으로 열리지 않고 바로 내려받아지며, 저장되는 파일명은 한글입니다(예: `리스크관리_추진_가이드.pdf`).

- 웹 서버나 사내 웹에 올려서 열면(주소가 `http://` 또는 `https://`) 위와 같이 바로 내려받아집니다.
- `index.html`을 더블클릭해 열면(주소가 `file://`) Chrome·Edge는 보안 규칙상 다운로드 지정을 무시하고 PDF를 같은 탭에서 엽니다. 이때는 PDF 화면에서 저장(Ctrl+S)하거나, 파일명을 오른쪽 클릭해 「다른 이름으로 링크 저장」을 사용하세요.

## 내용 수정하기

`index.html`을 메모장이나 코드 편집기로 열어 해당 글을 찾아 고칩니다.

- **제보 채널 안내**: `[기관 지정 제보 채널 URL 입력]`, `[담당 부서 연락처 입력]`, `[운영 시간 입력]`을 실제 정보로 교체합니다.
- **뉴스 목록**: 「리스크 규제 뉴스」의 항목은 화면 구성을 위한 예시입니다. 제목, 날짜, 설명을 실제 공지로 교체하고, 아래 「예시입니다」 안내 문구는 지웁니다.
- **FAQ**: 질문과 답변을 같은 형식으로 추가하거나 고칩니다. 질문 앞 태그(`리스크 관리` 등)가 카테고리 기준이며, 새 카테고리를 만들려면 같은 이름의 `cat-btn` 버튼을 FAQ 위 버튼 묶음에 추가합니다.
- **참고 문서 목록**: `files/`에 PDF를 추가하면 `index.html`의 `file-item` 블록 하나를 복사해 경로(`href`), 저장 이름(`download`), 설명, 용량을 고칩니다. 용량은 직접 적는 값이라 PDF가 바뀌면 함께 고쳐야 합니다.
- **내려받기 양식**: 파일 안쪽 스크립트의 표 내용을 고치면 내려받는 CSV 내용이 바뀝니다.

수정 후에는 브라우저에서 새로고침(F5)해 확인합니다. 원래대로 되돌리려면 `이전버전/portal-v2.html`을 `index.html`로 복사하세요.

## 개인정보

이 포털은 입력 내용(자가점검, 검색어)을 저장하거나 외부로 보내지 않습니다. 모두 브라우저 화면에서만 처리되며 새로고침하면 사라집니다.
